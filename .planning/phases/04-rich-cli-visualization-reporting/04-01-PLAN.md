2. Create `src/arr_oldies/reporting/formatters.py` implementing formatting utilities:
   - Implement `format_size(bytes_val: int) -> str`:
     - If `bytes_val < 0`, return `"0 B"`.
     - If `bytes_val < 1024`, return `f"{bytes_val} B"`.
     - Scale by 1024 across units `["KiB", "MiB", "GiB", "TiB", "PiB"]`.
     - Format as `f"{val:.2f} {unit}"`.
   - Implement `get_age_color(age_days: int, is_legacy: bool = False) -> str`:
     - If `is_legacy`: return `"dim"`.
     - If `age_days >= 730` (2+ years): return `"bold red"`.
     - If `age_days >= 365` (1-2 years): return `"yellow"`.
     - If `age_days >= 180` (6-12 months): return `"cyan"`.
     - Else (< 180 days): return `"green"`.
   - Implement `format_age_markup(age_days: int, is_legacy: bool = False) -> str`:
     - Compute color via `get_age_color(age_days, is_legacy)`.
     - If `age_days >= 365`: format as `f"{age_days:,} d ({age_days / 365.25:.1f}y)"`.
     - Elif `age_days >= 30`: format as `f"{age_days:,} d ({age_days / 30.4:.1f}m)"`.
     - Else: format as `f"{age_days} d"`.
     - If `is_legacy`: return `f"[{color}]{formatted} [dim italic](legacy)[/dim italic][/{color}]"`.
     - Else: return `f"[{color}]{formatted}[/{color}]"`.
   - Implement `format_instance_badge(instance_name: str, instance_type: InstanceType) -> str`:
     - If `instance_type == InstanceType.RADARR`: return `f"[bold cyan]{instance_name}[/bold cyan]"`.
     - Else: return `f"[bold magenta]{instance_name}[/bold magenta]"`.
   - Implement `format_audio_languages(languages: list[str]) -> str`:
     - If not languages: return `"[dim]None[/dim]"`.
     - For each language: if lowercase in `("english", "eng", "en")`: wrap in `[green]...[/green]`; elif in `("japanese", "jpn", "ja")`: wrap in `[blue]...[/blue]`; else wrap in `[white]...[/white]`.
     - Return comma-joined list.
   - Implement `format_media_title(item: MediaInventoryItem) -> str`:
     - Use `rich.markup.escape(item.title)` to safely escape brackets in title string.
     - For `MediaType.MOVIE`: append `f" [dim]({item.year})[/dim]"` if `item.year`; append `f" [dim]· {item.resolution}[/dim]"` if `item.resolution`. Return styled string with `[bold white]{title}[/bold white]`.
     - For `MediaType.EPISODE`: append `f" [bold yellow]{item.formatted_episode}[/bold yellow]"` if `item.formatted_episode`; append `f" [dim]\"{rich.markup.escape(item.episode_title)}\"[/dim]"` if `item.episode_title`; append `f" [dim]· {item.resolution}[/dim]"` if `item.resolution`. Return styled string with `[bold white]{title}[/bold white]`.

3. Create `tests/test_formatters.py` verifying:
   - `format_size`: 0 bytes (`"0 B"`), 500 bytes (`"500 B"`), 1024 bytes (`"1.00 KiB"`), 1048576 bytes (`"1.00 MiB"`), 15500000000 bytes (`"14.44 GiB"`), 2199023255552 bytes (`"2.00 TiB"`), negative bytes (`"0 B"`).
   - `get_age_color`: >=730 days returns `"bold red"`, >=365 days returns `"yellow"`, >=180 days returns `"cyan"`, <180 days returns `"green"`, legacy returns `"dim"`.
   - `format_age_markup`: formatting for 800 days (`"800 d (2.2y)"` in red), 400 days (`"400 d (1.1y)"` in yellow), 200 days (`"200 d (6.6m)"` in cyan), 10 days (`"10 d"` in green), and legacy formatting with `(legacy)` tag.
   - `format_instance_badge`: Radarr instance produces bold cyan markup, Sonarr instance produces bold magenta markup.
   - `format_audio_languages`: empty list produces `"[dim]None[/dim]"`, English produces `[green]English[/green]`, Japanese produces `[blue]Japanese[/blue]`, other languages produce `[white]French[/white]`, multiple languages produce comma-joined badges.
   - `format_media_title`: movie with year and resolution, episode with formatted episode code and episode title, media titles containing brackets `[Director's Cut]` escaping markup safely.
