   - Implement `build_json_payload(items: list[MediaInventoryItem], summary: InventorySummary, target_instances: list[str], total_scanned: int, limit: int | None = None, sort_key: SortKey = SortKey.IMPORT_DATE, sort_direction: SortDirection = SortDirection.ASC) -> dict[str, Any]`:
     - Slice displayed items: `displayed_items = items[:limit] if limit else items`.
     - Compute displayed size: `displayed_size = sum(item.size_bytes for item in displayed_items)`.

     - Construct `summary`: dictionary with `total_items` (summary.total_items), `total_size_bytes` (summary.total_size_bytes), `total_size_human` (format_size(summary.total_size_bytes)), `movie_count` (summary.movie_count), `episode_count` (summary.episode_count), `legacy_count` (summary.legacy_count), `oldest_import_date` (ISO string or None), `newest_import_date` (ISO string or None), `date_range_spanned_days` (span_days), `potential_space_freed_bytes` (displayed_size), `potential_space_freed_human` (format_size(displayed_size)), `instances_breakdown` (summary.instances_breakdown).

     - Return `{ "metadata": metadata, "summary": summary_data, "items": item_records }`.

     - Call `build_json_payload(...)`.

     - `history: Annotated[bool, typer.Option("--history", "--history-only", help="Filter only items with history records.")] = False`
     - `sort: Annotated[SortKey, typer.Option("--sort", "-s", help="Sort field ('import_date', 'grab_date', 'size', 'title', 'age').")] = SortKey.IMPORT_DATE`
     - `sort_dir: Annotated[SortDirection, typer.Option("--sort-dir", "--order", help="Sort direction ('asc', 'desc').")] = SortDirection.ASC`
     - `limit: Annotated[int | None, typer.Option("--limit", "-n", min=1, help="Limit output to top N items.")] = None`
     - `format: Annotated[OutputFormat, typer.Option("--format", "-f", help="Output format ('table' or 'json').")] = OutputFormat.TABLE`
     - `summary: Annotated[bool, typer.Option("--summary/--no-summary", help="Display summary metrics panel (table mode only).")] = True`
   - Command Execution Pipeline:
     1. Load configuration via `load_config(effective_config)` (catch `ConfigError`, call `print_error`, raise `typer.Exit(code=EXIT_CONFIG_ERROR)`).
     2. Resolve target instances via `resolve_target_instances(...)` (catch `InstanceError`, call `print_error`, raise `typer.Exit(code=EXIT_CONFIG_ERROR)`).
     3. Parse filter arguments using `parse_size`, `parse_age_cutoff`, `parse_date_cutoff` (catch `ParseError`, call `print_error`, raise `typer.Exit(code=EXIT_CONFIG_ERROR)`). Build `InventoryFilter`.
     4. Concurrently fetch data across instances using `MultiInstanceFetcher().fetch_all_instances_data(target_instances)`. If `format == OutputFormat.TABLE`, wrap with `stderr_console.status("[bold cyan]Scanning instances and fetching history records...[/bold cyan]")`. If all instances fail, call `print_error` and raise `typer.Exit(code=EXIT_PROBE_ERROR)`. If some fail, emit warning messages to `stderr_console`.
     5. Correlate media items using `HistoryCorrelator().correlate_instance(res.data)` for each successful result. Store `total_scanned_count = len(all_items)`.
     6. Filter inventory with `InventoryEngine().filter_inventory(all_items, criteria)`.
     7. Sort inventory with `InventoryEngine().sort_inventory(filtered_items, sort_key=sort, direction=sort_dir)`.
     8. Generate summary metrics with `InventoryEngine().generate_summary(sorted_items)`.
     9. Apply limit: `display_items = sorted_items[:limit] if limit else sorted_items`.
     10. Render output:
         - If `format == OutputFormat.JSON`: call `export_inventory_json(...)` and emit via `typer.echo(json_output)`.
         - Else (`format == OutputFormat.TABLE`):
           - If not sorted_items: `stdout_console.print("[yellow]No media items matched the specified criteria.[/yellow]")`.
           - Else: render and print `render_inventory_table(display_items, total_count=len(sorted_items), limit=limit)`.
           - If `summary`: render and print `render_summary_panel(inventory_summary, displayed_items_count=len(display_items), displayed_size_bytes=sum(i.size_bytes for i in display_items))`.
     11. Exit with `code=EXIT_SUCCESS`.
