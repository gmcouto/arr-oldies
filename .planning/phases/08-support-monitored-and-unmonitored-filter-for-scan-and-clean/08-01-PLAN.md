<objective>
**As a** media server administrator,
**I want to** filter media items by their monitored status using `--monitored` (or `--only-monitored` / `--monitored-only`) and `--unmonitored` (or `--only-unmonitored` / `--unmonitored-only`) in `scan` and `clean` commands,
**so that** I can inspect active vs abandoned media and execute cleanup or unmonitor actions (e.g. `clean --unmonitor --only-monitored`) without performing redundant operations on already unmonitored items.

Purpose: Implement monitored status extraction from Radarr/Sonarr data models, add monitored filtering to `InventoryFilter` and `InventoryEngine`, expose `--monitored` and `--unmonitored` CLI flags with mutual exclusion validation, and ensure end-to-end integration across reporting and action commands.
Output: Updated inventory models, updated history correlators, updated inventory engine, updated CLI commands, and comprehensive unit and integration test suites.
</objective>

<name>Task 1: Add monitored status to MediaInventoryItem, InventoryFilter, Correlators, and InventoryEngine</name>
<description>
1. In `src/arr_oldies/inventory/models.py`:
   - Add `monitored: bool = True` field to `MediaInventoryItem` with default `True` to maintain backward compatibility.
   - Add `monitored_only: bool = False` and `unmonitored_only: bool = False` fields to `InventoryFilter`.
2. In `src/arr_oldies/inventory/correlator.py`:
   - In `_correlate_radarr`: Extract `monitored = movie.monitored if movie is not None else True` and pass `monitored=monitored` when instantiating `MediaInventoryItem`.
   - In `_correlate_sonarr`: Extract `monitored = any(ep.monitored for ep in episodes) if episodes else (series.monitored if series is not None else True)` and pass `monitored=monitored` when instantiating `MediaInventoryItem`.
3. In `src/arr_oldies/inventory/engine.py`:
   - In `filter_inventory`: Add filtering rules:
     ```python
     if criteria.monitored_only and not item.monitored:
         continue
     if criteria.unmonitored_only and item.monitored:
         continue
     ```
4. Unit tests:
   - In `tests/test_inventory_models.py`:
     - Test `MediaInventoryItem` instantiation with `monitored=True` and `monitored=False`.
     - Test `MediaInventoryItem` default `monitored=True`.
     - Test `InventoryFilter` default `monitored_only=False` and `unmonitored_only=False`.
     - Test JSON serialization preserves `monitored` boolean field.
   - In `tests/test_correlator_radarr.py`:
     - Test Radarr movie file correlation with `movie.monitored=True` and `movie.monitored=False`.
     - Test fallback when movie object is missing (`monitored=True`).
   - In `tests/test_correlator_sonarr.py`:
     - Test Sonarr single episode file with `episode.monitored=True` vs `episode.monitored=False`.
     - Test Sonarr multi-episode file with mixed monitored states (`any` returns `True`).
     - Test Sonarr multi-episode file where all episodes are unmonitored (`monitored=False`).
     - Test Sonarr fallback to `series.monitored` when `episodes` list is empty.
   - In `tests/test_inventory_engine.py`:
     - Test `filter_inventory` with `monitored_only=True` returning only monitored items.
     - Test `filter_inventory` with `unmonitored_only=True` returning only unmonitored items.
     - Test default filter returning all items.
</description>
