<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| CLI Invocation -> Execution Guard | Action flags (`--delete`, `--remove`, etc.) and execution flags (`--execute`, `--yes`) processed before mutation |
| Stdin / Terminal -> Interactive Prompt | Interactive confirmation responses (`[y/N]`) read from terminal stream |
| Process Streams -> Output Stream | Stdout and stderr separation for machine-readable JSON pipelines |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-05-01 | Tampering / Denial of Service | `src/arr_oldies/cli.py`, `src/arr_oldies/actions/confirmation.py` | critical | mitigate | Default to dry-run simulation mode (ACT-01); require explicit `--execute` flag (ACT-06) and render high-contrast confirmation warning panel listing items and space freed with `[y/N]` prompt before mutations. |
| T-05-02 | Denial of Service | `src/arr_oldies/cli.py` | high | mitigate | Detect non-interactive stdin (`sys.stdin.isatty() is False`); if `--execute` is supplied without `--yes`, fail fast with exit code 1 to avoid subprocess deadlocks in cron jobs or automated scripts. |
| T-05-05 | Information Disclosure / Tampering | `src/arr_oldies/cli.py`, `src/arr_oldies/actions/confirmation.py` | medium | mitigate | Enforce pure JSON payload serialization to stdout when `--format json` is active; redirect all confirmation panels, prompts, warnings, and spinners to stderr [ASVS V13]. |
| T-05-SC | Tampering | pip/runtime dependencies | high | mitigate | Package legitimacy audit verified; using existing pinned `rich>=13.7.0`, `typer>=0.12.0` in `.venv`. |
</threat_model>
