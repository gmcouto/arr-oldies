     - Instantiate API clients for instances: `clients: dict[str, BaseArrClient] = {inst.name: create_arr_client(inst) for inst in instances}`.
     - Record `start_time = time.perf_counter()`.
     - Initialize `results: list[ActionResult] = []`.
     - Group and deduplicate series-level unmonitoring (per ACT-03):
       - If `ActionType.UNMONITOR in plan.target_actions`: track `unmonitored_series: set[tuple[str, int]] = set()` (instance_name, series_id) to avoid redundant PUT calls for multiple episodes of the same show.
     - Execute mutation operations per `ActionItem` in strict safe order (per C-02, T-05-03):
       - Step 1 (`ActionType.UNMONITOR`):
         - For Radarr (movies): call `await client.unmonitor_movie(item.movie_id)` if `item.movie_id`.
         - For Sonarr (series): if `(item.instance_name, item.series_id)` not in `unmonitored_series` and `item.series_id`: call `await client.unmonitor_series(item.series_id)`, add to `unmonitored_series`.
         - Append `ActionResult(item_id=item.id, instance_name=item.instance_name, action_type=ActionType.UNMONITOR, success=True)`. Catch exceptions and append `ActionResult(..., success=False, error_message=str(exc))`.
       - Step 2 (`ActionType.UNMONITOR_EPISODE`):
         - For Sonarr: call `await client.unmonitor_episodes(item.episode_ids)` if `item.episode_ids`.
         - Append `ActionResult(item_id=item.id, instance_name=item.instance_name, action_type=ActionType.UNMONITOR_EPISODE, success=True)`. Catch exceptions and append `ActionResult(..., success=False, error_message=str(exc))`.
       - Step 3 (`ActionType.DELETE` when `REMOVE` not requested):
         - For Radarr: call `await client.delete_movie_file(item.movie_file_id)` if `item.movie_file_id`.
         - For Sonarr: call `await client.delete_episode_file(item.episode_file_id)` if `item.episode_file_id`.
         - Append `ActionResult(item_id=item.id, instance_name=item.instance_name, action_type=ActionType.DELETE, success=True, freed_bytes=item.size_bytes)`. Catch exceptions and append `ActionResult(..., success=False, error_message=str(exc))`.
       - Step 4 (`ActionType.REMOVE`):
         - Determine `delete_files = ActionType.DELETE in item.action_types`.
         - For Radarr: call `await client.delete_movie(item.movie_id, delete_files=delete_files)` if `item.movie_id`.
         - For Sonarr: call `await client.delete_series(item.series_id, delete_files=delete_files)` if `item.series_id`.
         - Append `ActionResult(item_id=item.id, instance_name=item.instance_name, action_type=ActionType.REMOVE, success=True, freed_bytes=item.size_bytes if delete_files else 0)`. Catch exceptions and append `ActionResult(..., success=False, error_message=str(exc))`.
     - Calculate totals:
       - `successful_count = sum(1 for r in results if r.success)`
       - `failed_count = sum(1 for r in results if not r.success)`
       - `total_freed_bytes = sum(r.freed_bytes for r in results if r.success)`
       - `duration_seconds = round(time.perf_counter() - start_time, 3)`
     - Close all instantiated clients with `await client.aclose()`.
     - Return `ExecutionReport(mode="execute", target_actions=plan.target_actions, total_attempted=len(results), successful_count=successful_count, failed_count=failed_count, total_freed_bytes=total_freed_bytes, results=results, duration_seconds=duration_seconds)`.
   - Implement `export_report_json(self, report: ExecutionReport, indent: int = 2) -> str`:
     - Serialize `ExecutionReport` to JSON format with summary metrics and per-item results.
     - Return formatted JSON string.
