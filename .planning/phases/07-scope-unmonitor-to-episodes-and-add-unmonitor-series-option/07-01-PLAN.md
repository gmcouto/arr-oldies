<objective>
**As a** media server administrator,
**I want to** run `--unmonitor` to unmonitor individual stale episodes (or movies) without unmonitoring the entire TV series, and use `--unmonitor-series` when I explicitly want to unmonitor the whole show,
**so that** deleting older episodes of an ongoing series does not accidentally stop Sonarr from tracking and downloading new future episodes of that show.

Purpose: Refactor the unmonitor action semantics across domain models, execution engine, UI confirmation, and Typer CLI options so `--unmonitor` operates at the granular media file level (episodes for TV, movies for movies), remove `--unmonitor-episode`, and introduce `--unmonitor-series`.
Output: Updated action models, modified executor and confirmation formatting, updated CLI clean options, and updated test suite.
</objective>

       - For Radarr (movies): Call `client.unmonitor_movie(item.movie_id)` as before.

   - Verify `UNMONITOR_SERIES` is pruned on Movie items.
</description>
