Pick event with date closest to/matching `movie_file.date_added` or latest import event.

1. Create `src/arr_oldies/inventory/engine.py` implementing `InventoryEngine`:
   - `__init__(self, normalizer: LanguageNormalizer | None = None)`: store `self.normalizer = normalizer or LanguageNormalizer()`.
   - Implement `filter_inventory(self, items: list[MediaInventoryItem], criteria: InventoryFilter) -> list[MediaInventoryItem]`:
     - Iterate through items and evaluate predicates:
       - Media type filter: if `criteria.media_types` and `item.media_type not in criteria.media_types`: skip.
       - Instance name filter: if `criteria.instance_names`: check if `item.instance_name.lower()` in `{n.lower() for n in criteria.instance_names}`; if not: skip.
       - Size bounds filter: if `criteria.min_size_bytes is not None` and `item.size_bytes < criteria.min_size_bytes`: skip. If `criteria.max_size_bytes is not None` and `item.size_bytes > criteria.max_size_bytes`: skip.
       - Age bounds filter (days): if `criteria.min_age_days is not None` and `item.age_days < criteria.min_age_days`: skip. If `criteria.max_age_days is not None` and `item.age_days > criteria.max_age_days`: skip.
       - Date bounds filter: if `criteria.before_date is not None` and `item.import_date >= criteria.before_date`: skip. If `criteria.after_date is not None` and `item.import_date <= criteria.after_date`: skip.
       - Legacy / History flags: if `criteria.legacy_only` and `item.has_history`: skip. If `criteria.history_only` and `not item.has_history`: skip.
       - Audio language filter: if `criteria.audio_langs`: if not any `self.normalizer.matches(item.audio_languages, q)` for `q` in `criteria.audio_langs`: skip.
     - Return filtered list.
   - Implement `sort_inventory(self, items: list[MediaInventoryItem], sort_key: SortKey = SortKey.IMPORT_DATE, direction: SortDirection = SortDirection.ASC) -> list[MediaInventoryItem]`:
     - Determine `reverse = direction == SortDirection.DESC`.
     - Define sort key extractor with stable tie-breaking:
       - `SortKey.IMPORT_DATE`: return `(item.import_date, item.title.lower(), item.id)`
       - `SortKey.GRAB_DATE`: return `(item.grab_date or item.import_date, item.title.lower(), item.id)`
       - `SortKey.SIZE`: return `(item.size_bytes, item.import_date, item.title.lower(), item.id)`
       - `SortKey.TITLE`: return `(item.title.lower(), item.import_date, item.id)`
       - `SortKey.AGE`: return `(item.age_days, item.title.lower(), item.id)`
     - Return `sorted(items, key=_sort_extractor, reverse=reverse)`.
   - Implement `generate_summary(self, items: list[MediaInventoryItem]) -> InventorySummary`:
     - If not items: return `InventorySummary()`.
     - Compute: `total_items = len(items)`, `total_size_bytes = sum(i.size_bytes for i in items)`, `movie_count = sum(1 for i in items if i.media_type == MediaType.MOVIE)`, `episode_count = sum(1 for i in items if i.media_type == MediaType.EPISODE)`, `legacy_count = sum(1 for i in items if i.is_legacy)`.
     - Compute `oldest_import_date = min(i.import_date for i in items)`, `newest_import_date = max(i.import_date for i in items)`.
     - Compute `oldest_grab_date = min((i.grab_date for i in items if i.grab_date is not None), default=None)`.
     - Compute `instances_breakdown`: dictionary mapping instance name to item count.
     - Return populated `InventorySummary`.
