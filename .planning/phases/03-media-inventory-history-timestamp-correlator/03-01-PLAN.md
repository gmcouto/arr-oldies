2. Create `src/arr_oldies/inventory/parser.py` implementing human string parsing utilities:
   - Define `SIZE_REGEX = re.compile(r"^\s*([0-9]+(?:\.[0-9]+)?)\s*([a-zA-Z]*)\s*$")`.
   - Define `AGE_REGEX = re.compile(r"^\s*([0-9]+)\s*([a-zA-Z]*)\s*$")`.
   - Define `SIZE_MULTIPLIERS: dict[str, int]` mapping `""`: 1, `"b"`: 1, `"k"`: 1024, `"kb"`: 1000, `"kib"`: 1024, `"m"`: 1024**2, `"mb"`: 1000**2, `"mib"`: 1024**2, `"g"`: 1024**3, `"gb"`: 1000**3, `"gib"`: 1024**3, `"t"`: 1024**4, `"tb"`: 1000**4, `"tib"`: 1024**4.
   - Implement `parse_size(size_str: str) -> int`:
     - Match against `SIZE_REGEX`; if no match, raise `ParseError(f"Invalid size specification: '{size_str}'. Examples: '500MB', '2GB', '1.5GiB'.")`.
     - Extract numeric value and unit suffix; lookup multiplier in `SIZE_MULTIPLIERS`. If unit is unknown, raise `ParseError(f"Unknown size unit '{unit_raw}' in '{size_str}'.")`.
     - Return `int(float(val_str) * multiplier)`.
   - Implement `parse_age_cutoff(age_str: str) -> int`:
     - Match against `AGE_REGEX`; if no match, raise `ParseError(f"Invalid age specification: '{age_str}'. Examples: '30d', '6m', '1y', '2w'.")`.
     - Extract integer value and unit suffix; support `"", "d", "day", "days"` -> val; `"w", "week", "weeks"` -> val * 7; `"m", "month", "months", "mo"` -> val * 30; `"y", "year", "years", "yr"` -> val * 365.
     - If unit is unknown, raise `ParseError(f"Unknown age unit '{unit_raw}' in '{age_str}'. Supported units: d (days), w (weeks), m (months), y (years).")`.
     - Return calculated integer days.
   - Implement `parse_date_cutoff(date_str: str) -> datetime`:
     - Strip whitespace; if `"T"` in string, parse using `datetime.fromisoformat(clean.replace("Z", "+00:00"))`; otherwise parse using `datetime.strptime(clean, "%Y-%m-%d")`.
     - Ensure datetime is timezone-aware in UTC (`dt.replace(tzinfo=timezone.utc)` if naive, else `dt.astimezone(timezone.utc)`).
     - If parsing fails with `ValueError`, catch and raise `ParseError(f"Invalid date format: '{date_str}'. Expected 'YYYY-MM-DD' or ISO-8601 format.")` from the original exception.

3. Create `tests/test_parser.py` verifying:
   - Valid size strings: `"500B"`, `"500MB"`, `"500MiB"`, `"2GB"`, `"2GiB"`, `"1.5GB"`, `"1TB"`, `"1TiB"`.
   - Invalid size strings raising `ParseError` (`"invalid"`, `"500PB"`).
   - Valid age strings: `"30"`, `"30d"`, `"2w"`, `"6m"`, `"1y"`.

   - Valid date strings: `"2024-01-15"` and `"2024-01-15T14:30:00Z"` returning UTC datetimes.
   - Invalid date strings raising `ParseError` (`"not-a-date"`, `"2024/01/15"`).
