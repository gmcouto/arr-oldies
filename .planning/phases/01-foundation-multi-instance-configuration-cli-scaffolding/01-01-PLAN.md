# Plan 01-01: Project Foundation, Models & Configuration Loader

Establish the Python project structure, Pydantic v2 data models for Radarr and Sonarr instances, and a robust hierarchical YAML configuration loader with clean error diagnostics and credential protection.

<threat_model>
## Threat Model (STRIDE / ASVS Level 1)

| Threat ID | Category | Component | Description | Mitigation Strategy |
|---|---|---|---|---|
| T-01-01 | Information Disclosure | `models.py`, `console.py` | Credential exposure (API keys) in terminal output, logs, or string representations | Mitigate with Pydantic `SecretStr` storage, `mask_secret` helper, and never printing raw secret in cleartext [D-16]. |
| T-01-02 | Security Misconfiguration | `models.py`, `prober.py` | Insecure SSL bypasses without user intent | Mitigate with default `verify_ssl: true` in `DefaultsConfig`, requiring explicit override [D-04]. |
| T-01-03 | Tampering / Code Execution | `config.py` | Arbitrary code execution via unsafe YAML deserialization | Mitigate with `yaml.safe_load` exclusively [D-03]. |
</threat_model>

### Task 2: Pydantic v2 Configuration Schemas with Credential Protection

<read_first>

<action>
1. Implement `src/arr_oldies/models.py` with Pydantic v2 schemas:
   - `InstanceType(StrEnum)`: `RADARR = "radarr"`, `SONARR = "sonarr"`.
   - `DefaultsConfig(BaseModel)`: `timeout: float = Field(default=30.0, ge=1.0, le=300.0)`, `verify_ssl: bool = Field(default=True)`.
   - `InstanceConfig(BaseModel)`:
     - `name: str = Field(..., min_length=1, max_length=64)`
     - `type: InstanceType`
     - `url: str = Field(...)`
     - `api_key: SecretStr = Field(...)`
     - `timeout: float | None = Field(default=None, ge=1.0, le=300.0)`
     - `verify_ssl: bool | None = Field(default=None)`
     - `@field_validator("url")`: Strips whitespace, trims trailing slashes (`v.strip().rstrip('/')`), and ensures prefix is `http://` or `https://` (raising `ValueError("URL must start with http:// or https://")`).
   - `AppConfig(BaseModel)`:
     - `defaults: DefaultsConfig = Field(default_factory=DefaultsConfig)`
     - `instances: list[InstanceConfig] = Field(default_factory=list)`
     - `@model_validator(mode="after")`:
       - Enforces uniqueness of instance names case-insensitively, raising `ValueError(f"Duplicate instance name found: '{inst.name}'")` on duplicate.
       - Inherits `defaults.timeout` and `defaults.verify_ssl` onto any instance where the corresponding field is `None` per D-04.
   - `ProbeResult(BaseModel)`:
     - `instance_name: str`
     - `instance_type: InstanceType`
     - `url: str`
     - `success: bool`
     - `version: str | None = None`
     - `latency_ms: float = 0.0`
     - `error_message: str | None = None`
2. Create `tests/test_models.py` covering:
   - URL normalization (stripping trailing slash: `http://localhost:7878/` -> `http://localhost:7878`).
   - Invalid URL scheme rejection (e.g. `ftp://localhost`, `localhost:7878`).
   - Duplicate instance name rejection (e.g. `Radarr-1` and `radarr-1`).
   - Defaults inheritance (verifying instance receives `defaults.timeout` when omitted, but retains override when specified).
   - `SecretStr` credential masking (verifying `str(instance)` or `instance.model_dump()` does not expose raw API key, and `.get_secret_value()` returns raw string) per T-01-01 and D-16.
</action>

### Task 3: Hierarchical YAML Configuration Loader with Error Diagnostics

<read_first>
- .planning/phases/01-foundation-multi-instance-configuration-cli-scaffolding/01-CONTEXT.md (D-01, D-03, D-08, D-14)
- .planning/phases/01-foundation-multi-instance-configuration-cli-scaffolding/01-RESEARCH.md §104-126
</read_first>

<action>
1. Implement `src/arr_oldies/config.py`:
   - `find_config_file(explicit_path: Path | str | None = None) -> Path`:
     - If `explicit_path` is passed: check existence. If exists, return resolved `Path`. If not, raise `ConfigNotFoundError(f"Specified config file not found: {explicit_path}")`.
     - In current working directory (`Path.cwd()`): check `arr-oldies.yaml`, `arr-oldies.yml`, `config.yaml`, `config.yml`. Return first existing.
     - In user home directory (`Path.home() / ".config" / "arr-oldies"`): check `config.yaml`, `config.yml`, `arr-oldies.yaml`, `arr-oldies.yml`. Return first existing.
     - If no file found, raise `ConfigNotFoundError` listing all searched locations.
   - `load_config(config_path: Path | str | None = None) -> AppConfig`:
     - Calls `find_config_file(config_path)` to resolve the target path.
     - Reads file text with UTF-8 encoding.
     - Parses using `yaml.safe_load(content)` (satisfying T-01-03 and D-03). Catches `yaml.YAMLError` and raises `ConfigFormatError(f"Invalid YAML syntax in {path}: {exc}")`.
     - Validates that the loaded data is a `dict`. If empty or None, raises `ConfigValidationError(f"Configuration file is empty: {path}")`. If not a dict, raises `ConfigValidationError(f"Root configuration must be a mapping in {path}")`.
     - Instantiates `AppConfig.model_validate(data)`. Catches `pydantic.ValidationError` and constructs a clean, human-readable summary of missing or invalid fields, raising `ConfigValidationError(summary)` per D-08 and D-14.
2. Create `tests/test_config.py` covering:
   - Explicit `--config` path resolution (existing vs non-existent).
   - Discovery order: CWD `./arr-oldies.yaml` > `./config.yaml` > `~/.config/arr-oldies/config.yaml`.
   - Valid YAML configuration loading returning populated `AppConfig`.
   - Malformed YAML raising `ConfigFormatError`.
   - Missing required fields / schema violations raising `ConfigValidationError` with descriptive message.
   - Empty YAML file raising `ConfigValidationError`.
</action>
