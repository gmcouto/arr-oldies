## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CLI Engine -> *arr HTTP REST API | Outbound HTTP requests transmitting API keys and receiving untrusted JSON payloads |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-02-01 | Information Disclosure | `src/arr_oldies/api/base.py`, `src/arr_oldies/api/models.py` | high | mitigate | Extract `api_key` only inside `X-Api-Key` headers via `.get_secret_value()`; never log raw headers or append API keys to URL query params [D-16]. |
| T-02-02 | Denial of Service / Lockup | `src/arr_oldies/api/base.py` | high | mitigate | Configure `httpx.Limits(max_connections=10, max_keepalive_connections=5)` and apply exponential backoff with random jitter on 429/503/lock errors. |
| T-02-03 | Security Misconfiguration | `src/arr_oldies/api/base.py` | medium | mitigate | Explicitly pass `verify=self.instance.verify_ssl` (defaulting to True) into `httpx.AsyncClient`. |
| T-02-SC | Tampering | npm/pip installs | high | mitigate | Verified packages against registry and locked dependencies. |
</threat_model>

     - `SONARR_HISTORY_SERIES_ENDPOINT = "/api/v3/history/series"`

2. Update `src/arr_oldies/exceptions.py` to add the API client exception hierarchy:
   - `ArrClientError(ArrOldiesError)`: Base exception for all *arr API client communication failures.
   - `ArrConnectionError(ArrClientError)`: Network connection failure, host unreachable, or DNS resolution failure.
   - `ArrTimeoutError(ArrClientError)`: HTTP request or socket connect timeout exceeded.
   - `ArrAuthenticationError(ArrClientError)`: HTTP 401 or 403: Invalid API key or unauthorized access.
   - `ArrNotFoundError(ArrClientError)`: HTTP 404: Endpoint or requested resource not found.
   - `ArrResponseError(ArrClientError)`: Server returned an unexpected HTTP 4xx or 5xx status code (stores `status_code: int` and `message: str`).
   - `ArrDatabaseLockedError(ArrResponseError)`: Server SQLite database is locked (SQLiteBusyException / SQLite Error 5).

3. Create `src/arr_oldies/api/__init__.py` exporting models and base client.

4. Create `src/arr_oldies/api/models.py` with Pydantic v2 models:
   - `ApiBaseModel(BaseModel)`: configured with `model_config = ConfigDict(extra="ignore", populate_by_name=True)`.
   - `MediaInfo(ApiBaseModel)`: `audio_codec`, `audio_channels`, `audio_profile`, `audio_languages`, `audio_title`, `video_codec`, `video_bitdepth`, `resolution`, `run_time`, `subtitles`.
   - Radarr models: `RadarrMovieFile`, `RadarrMovie`, `RadarrHistoryRecord`, `RadarrHistoryPage`.
   - Sonarr models: `SonarrSeason`, `SonarrSeries`, `SonarrEpisodeFile`, `SonarrEpisode`, `SonarrHistoryRecord`, `SonarrHistoryPage`.

5. Create `tests/test_api_models.py` verifying parsing, field aliases, extra field tolerance, and ISO timestamps.
