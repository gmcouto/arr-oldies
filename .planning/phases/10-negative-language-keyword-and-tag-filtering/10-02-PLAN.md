<name>Task 1: Add filter criteria to InventoryFilter and implement negative language, title substring, and tag filters in InventoryEngine</name>
<description>
1. In `src/arr_oldies/inventory/models.py`:
   - Add fields to `InventoryFilter`:
     - `not_audio_langs: list[str] | None = None`
     - `titles: list[str] | None = None`
     - `tags: list[str] | None = None`
     - `not_tags: list[str] | None = None`
2. In `src/arr_oldies/inventory/engine.py`:
   - In `InventoryEngine.filter_inventory`:
     - Negative audio language filter (INVT-07):
       Check `if criteria.not_audio_langs and any(self.normalizer.matches(item.audio_languages, q) for q in criteria.not_audio_langs): continue`.
     - Title substring filter (INVT-08):
       Check `if criteria.titles:`. Iterate over `criteria.titles`, strip whitespace and convert to lowercase. If query is found in `item.title.lower()` or `(item.episode_title and query in item.episode_title.lower())`, mark as matched. If no query matched, `continue`.
     - Tag inclusion filter (INVT-09):
       Check `if criteria.tags:`. Compute `item_tags = {t.strip().lower() for t in item.tags}`. If `not any(q.strip().lower() in item_tags for q in criteria.tags if q.strip()): continue`.
     - Tag exclusion filter (INVT-09):
       Check `if criteria.not_tags:`. Compute `item_tags = {t.strip().lower() for t in item.tags}`. If `any(q.strip().lower() in item_tags for q in criteria.not_tags if q.strip()): continue`.
3. Unit tests:
   - In `tests/test_inventory_models.py`: Add `test_inventory_item_and_filter_new_fields` verifying `InventoryFilter` instantiates with `not_audio_langs`, `titles`, `tags`, and `not_tags`.
   - In `tests/test_inventory_engine.py`:
     - Add `test_filter_negative_audio_language` testing exclusion by ISO code (`pt-br`, `por`) and full name (`portuguese`, `japanese`).
     - Add `test_filter_title_substring_matching` testing case-insensitive substring matches across movie title, TV series title, and episode title.
     - Add `test_filter_tag_inclusion_and_exclusion` testing tag inclusion (`tags=["4k"]`) and tag exclusion (`not_tags=["archive"]`).
     - Add test combining positive and negative filters simultaneously.
</description>
